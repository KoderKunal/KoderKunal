# References

These sources ground the risk taxonomy and governance design. Model weights, control strengths, default ratings and severity thresholds are AgentGuard prototype assumptions, not values published by these frameworks.

1. OWASP GenAI Security Project, **Top 10 for Agentic Applications 2026** — primary taxonomy for ASI01–ASI10: https://genai.owasp.org/top-10-for-agentic-applications-2026/
2. OWASP, **Top 10 for Agentic Applications 2026 resource page**: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-2026/
3. OWASP, **LLM06:2025 Excessive Agency** — risks of assigning tool-calling authority and allowing unsafe actions from unexpected or manipulated outputs: https://genai.owasp.org/llmrisk/llm062025-excessive-agency/
4. NIST AI 600-1, **Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile** (26 July 2024): https://doi.org/10.6028/NIST.AI.600-1
5. NIST, **AI Risk Management Framework**: https://www.nist.gov/itl/ai-risk-management-framework
6. MITRE, **ATLAS** — adversary tactics and techniques against AI-enabled systems: https://atlas.mitre.org/
7. OWASP GenAI Security Project, **Agent Control Standard announcement** (September 2026): https://genai.owasp.org/2026/09/01/owasp-genai-security-project-unveils-2026-top-10-for-llm-applications-new-agent-control-standard-and-sponsors-as-community-tops-30000-members/

## Scope
AgentGuard uses these sources as taxonomy and design references. It is not an official OWASP implementation guide, NIST conformity assessment, MITRE evaluation or formal security control certification. Review the current authoritative resources before use in a real governance programme.
