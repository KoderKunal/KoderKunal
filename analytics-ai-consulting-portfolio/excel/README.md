# Excel implementation guide

The CSV datasets are generated by each project's analysis.py. Use Excel desktop for Power Query and PivotTables.

## Workforce Intelligence
1. Data → Get Data → From Text/CSV → select project-01-workforce-intelligence/data/hr_attrition_synthetic.csv.
2. In Power Query, trim text fields, check data types, check duplicate employee IDs, and add attrition_flag = if [attrition] = "Yes" then 1 else 0.
3. Load to a table named HR_Clean.
4. PivotTable: Rows = department; Values = Count of employee_id and Average of attrition_flag (format as %).
5. PivotTable: Rows = overtime; Columns = attrition; Values = Count of employee_id.
6. Add KPI formulas for headcount, leavers and attrition rate; create a column chart by department.

## AI Value Portfolio
1. Import project-02-ai-value-portfolio/data/ai_initiatives_synthetic.csv using Power Query.
2. Validate numeric types; trim sector/function/use-case text; check missing IDs and positive implementation costs.
3. Load to an Excel table called AI_Clean.
4. PivotTable: Rows = sector; Values = Count of initiative_id, Average of implementation cost, benefit and ROI.
5. PivotTable: Rows = business_function; Columns = sector; Values = Count of initiatives.
6. Add a scatter plot of implementation cost vs annual benefit and a readiness × governance-risk heatmap.

## VBA refresh
A macro-free workbook is preferred for distribution. If using VBA, review your module, import only trusted source, save your own working copy as .xlsm and follow your organisation's macro policy. Never enable unknown macros.

PivotTables show descriptive group differences; they do not establish causation. Interpret inferential tests separately and identify the dataset as synthetic.
